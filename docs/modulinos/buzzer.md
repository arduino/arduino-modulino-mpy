# Modulino Buzzer

![Modulino Buzzer](../assets/modulinos/buzzer.svg){ .modulino-illustration }

A piezo speaker that can play tones and melodies.

```python
from modulino import ModulinoBuzzer

buzzer = ModulinoBuzzer()
```
