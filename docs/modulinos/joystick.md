# Modulino Joystick

![Modulino Joystick](../assets/modulinos/joystick.svg){ .modulino-illustration }

Read the X/Y axis position and button state of a joystick.

```python
from modulino import ModulinoJoystick

joystick = ModulinoJoystick()
```
